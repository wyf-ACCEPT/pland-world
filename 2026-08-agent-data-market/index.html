Agent 训练数据市场

当「真实的 agent 交互记录」被当成商品，两个问题立刻摆在面前：到底谁在买、按什么标准买，以及这些数据要处理到什么程度才敢卖。这两个专题各回答一个。

一句话结论

公开市场上真正在买 agent 数据的，不是模型厂商本身——OpenAI、Anthropic、Cursor 都没有公开的采购入口。挂着实时需求的是中间商。而且他们付费买的单位不是「历史日志」，是「买方先出题、贡献者在受控环境里做完、带着验收和授权证据交付」。

换句话说：「攒一堆日志再脱敏转卖」这条路，市场已经用「按需生产」绕过去了。
