05 / TWO PATHS, DIFFERENT EVIDENCE

两条路径如何放在同一张图里？

售价反推与硬件正推回答不同问题。用同一模型、同一输入输出形状、同一延迟约束与实际计费 token 才能做经营对照。

01 / API 反推

商业上限与假设成本线。

GPT-6.1 Sol 与 Claude Sonnet 5.5 标准价同为 $2/$10；1K/1K、40% 假设毛利时，服务成本情景均为 $3.60/M 总 token。这不是厂商底层 GPU 成本。

02 / GPU 正推

采购、融资、托管都入账。

8×B200 跑 GPT-OSS-120B，公开云租价分摊为 $0.212/M 输出；中性工作情景约 $0.0755/M 输出，仍需核查配置与吞吐。

03 / 专用芯片

速度不是成本账本。

Groq 与 Cerebras 均对 GPT-OSS-120B 报价并展示单用户速度，但缺聚合吞吐与完整整机成本。Google TPU 的历史聚合测试则可算一部分云租金；仍非制造成本。

固定满载整机持续达到基准输出速率，全年按 8,760 小时折旧；没有闲置或维护停机。
两种分母API 章为百万输入＋输出总 token；硬件章为基准的百万输出 token，不能直接相减。
