# Token cost atlas · archive design

## Role

An independent Chinese research snapshot inside pland.world. Preserve the archived prices, assumptions, formulas, sources, sorting, and filters. Visual changes here never propagate to the original GPT Site, and source changes there do not propagate here.

## Visual system

- Canvas `#0e1116`, raised cards `#1a2029`, dark line `#2a313c`, primary ink `#e8ecf1`, secondary ink `#9aa6b4`, and pland.world gold `#e0a346`.
- Display headings use Fraunces and Noto Serif SC; body uses IBM Plex Sans; data and labels use IBM Plex Mono.
- The brand rail links back to pland.world. Cards and tables share the homepage's deep surfaces, quiet borders, and gold focus and link cues.
- Numeric heat cells retain independent per-column scales, using dark green for lower values, slate for middle values, and clay for higher values. Text remains bright on all stops. Color does not express model quality.
- The master table scrolls as one unit on narrow screens. No frozen first column.

## Behavior

The model/API scenario controls, tier and price ordering, group filters, and editable hardware cost fields must behave exactly as in the captured source version. The owned-cost bridge updates when hardware inputs change. The archive date is visible because this copy will not update automatically.
